Title: Chimata's Clothing Store

Main Character: Chimata
Boss: None
Enemies: Youkai

Story:
"Chimata's just opened her clothing store so the Gensokyo's residents can finally get a cool drip.
Shortly after opening, it got immediately shoplifred by bunch of rogue Youkai.
Chimata need to keep her store safe while serving her customers."

Gameplay:

- Action 2D sidescroller
- Up down left right movement
- No jump ability
- Simple bullet hell pattern
- Serve customers while fighting rogue youkai

Gameplay Details:
- Days system, day 1, day 2, day 3, etc
- Each day = 1 minutes

- Coin system:
-> Collected by: Killing youkai, serving customer
-> Lost by: Shoplifted by youkai, customer left
-> Coin is used to buy a new clothing material to make a cloth

- Score system, same as coin system but without loosing

- Cloth system, used for buff items, ex. Attack +10, Defense +12
- Cloth can be obtained by using coin at the end of each day

Game over condition:
- Negative Coin -> Debt ending
- 0 Health -> Dead

Win condition:
- No win condition, just top days and score, ex. Highscore: Day 12, Score 49281
